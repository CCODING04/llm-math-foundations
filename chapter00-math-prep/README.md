## 1. 符号速查卡 📇

> **核心**：符号速查卡——后续每一章都会反复使用这些符号，必须熟练认读。

> 类比：符号就像编程里的关键字——不用背，但碰到得认识。

### 1.1 Σ（求和）与 Π（连乘）

**Σ（Sigma）= 把一堆数加起来**

$$\sum_{i=1}^{4} x_i = x_1 + x_2 + x_3 + x_4$$

手算：若 x₁=2, x₂=3, x₃=1, x₄=4，则 Σ = 2+3+1+4 = **10**。

**Π（Pi）= 把一堆数乘起来**

$$\prod_{i=1}^{3} x_i = x_1 \times x_2 \times x_3$$

手算：若 x₁=2, x₂=3, x₃=4，则 Π = 2×3×4 = **24**。

> 💡 **LLM 关联**：Softmax 里 $\text{softmax}(z_i) = \frac{e^{z_i}}{\sum_j e^{z_j}}$，分母就是 Σ；语言模型算整个句子的概率时用 Π。

### 1.2 下标与上标约定

| 写法 | 含义 | 例子 |
|:---|:---|:---|
| $x_i$ | 第 i 个元素 | x₁=3, x₂=7 → i 是下标，表示编号 |
| $W^{(l)}$ | 第 l 层的权重矩阵 | W⁽¹⁾ 是第 1 层，W⁽²⁾ 是第 2 层 |
| $x^{(t)}$ | 第 t 个时间步的输入 | RNN 里常见 |

> 类比：下标像数组索引 `x[i]`，上标里的括号像层数标记。

### 1.3 argmax / argmin

- **argmax f(x)** = 让 f(x) 取最大值的那个 x（要的是"谁"，不是"多少"）
- **argmin f(x)** = 让 f(x) 取最小值的那个 x

例子：f(1)=3, f(2)=9, f(3)=5 → **argmax f(x) = 2**（不是 9！）

> 💡 **LLM 关联**：贪心解码就是 `argmax P(token | context)`，找出概率最大的那个 token。

### 1.4 log 和 exp 的 3 条核心规则

| 规则 | 公式 | 直觉 |
|:---|:---|:---|
| 乘→加 | $\log(ab) = \log a + \log b$ | log 把乘法"降级"成加法 |
| 幂→乘 | $\log(a^b) = b \cdot \log a$ | 指数可以"拉下来" |
| 互逆 | $\exp(\log x) = x$ | exp 是 log 的"撤销键" |

**为什么 ML 爱用 log？** 三个字：**稳、快、好**。
- **稳**：概率连乘容易下溢（小到计算机存不住），取 log 变连加就安全了
- **快**：加法比乘法好算，求导也简单
- **好**：交叉熵、KL 散度这些核心概念，用 log 表达最自然

```python
import numpy as np
# 概率连乘 vs log 连加
probs = [0.1, 0.05, 0.01, 0.001]
print("连乘:", np.prod(probs))           # 5e-08，很快溢出
print("log连加:", np.sum(np.log(probs))) # -16.8，数值稳定
```

## 2. 函数复合 —— 链式法则的学前班 🔗

> 类比：复合函数就像流水线——原料进第一台机器，半成品进第二台机器，最终产出成品。

### 2.1 直觉

**f(g(x))** 就是"把 x 先喂给 g，再把 g 的结果喂给 f"。

```
x → [g(x)] → 中间结果 → [f(·)] → 最终输出 y
```

### 2.2 例子：y = (2x + 1)²

拆开看：
- 内层 g(x) = 2x + 1
- 外层 f(u) = u²
- 复合：y = f(g(x)) = (2x+1)²

当 x=3 时：g(3)=7，f(7)=49，所以 y=49。

> 💡 **LLM 关联**：Transformer 每一层都是一次函数复合——输入经过注意力、FFN、LayerNorm，层层套叠。反向传播时，链式法则就是沿着这条流水线**倒着**走一遍。

## 3. 坐标系与向量图 📊

> 三个核心事实，记住就行。

**① 点** = 坐标系里的一个位置，用 (x, y) 描述。

**② 向量** = 从原点 (0,0) 到某个点的**箭头**，既有方向又有长度。
- 词嵌入就是一个高维向量——只不过从 2 维变成了 768 维或 4096 维。

**③ 斜率** = 曲线在某点的陡峭程度 = 该点切线的倾斜度。
- 斜率 > 0 → 函数在涨；斜率 < 0 → 函数在跌。
- 梯度就是多维版的斜率，告诉模型"往哪调参能让损失降最快"。

```
        │    · (2,3)  ← 点
        │   ╱
        │  ╱ ← 向量：从原点到 (2,3) 的箭头
        │ ╱
    ────┼────
        │
```

## 4. NumPy 极简入门 🐍

> **深入**：NumPy 是后续章节的代码验证工具。这里先混个脸熟，后面遇到再回来细看也行。

> 10 行代码，够用了。后面章节会反复用，这里先混个脸熟。

```python
import numpy as np

# 创建
a = np.array([1, 2, 3])           # 一维向量
W = np.array([[1, 2], [3, 4]])    # 2×2 矩阵

# 查看
print(a.shape)   # (3,)  → 一维，3个元素
print(W.shape)   # (2,2) → 二维，2行2列

# 矩阵乘法（@ 是矩阵乘法运算符）
b = np.array([[5], [6]])           # 2×1 列向量
print(W @ b)                       # [[17], [39]]
# 手算验证：[1×5+2×6, 3×5+4×6] = [17, 39] ✅
```

> 💡 **LLM 关联**：`W @ x` 就是神经网络一层的前向传播——权重矩阵乘以输入向量。

## ⚠️ 常见卡点

**卡点 1：Σ 求和看不懂**

- **困惑**：看到 $\sum_{i=1}^{n} x_i$ 就头疼，不知道在干嘛。
- **直觉**：Σ 就是一个 for 循环——"把这些数全加起来"。
- **正确理解**：展开成具体的加法就好了。$\sum_{i=1}^{4} x_i = x_1 + x_2 + x_3 + x_4$。代入数字：若 $x_1=2, x_2=3, x_3=1, x_4=4$，则 Σ = 2+3+1+4 = 10。遇到 Σ 永远先展开成具体的加法，就不慌了。

**卡点 2：log 到底在干嘛？**

- **困惑**：log 的公式记不住，不知道为什么要学它。
- **直觉**：log 是一个「翻译器」——把乘法翻译成加法。$\log(a \times b) = \log a + \log b$，乘法变成了加法，世界简单了。
- **正确理解**：在机器学习中，很多个概率连乘容易让计算机下溢（结果太小，存不住）。取 log 后变成连加，数值稳定，求导也方便。记住 log 的核心作用：**把乘法变加法，把大数变小数**。

## 🤔 思考题

1. **Σ 与 for 循环**：$\sum_{i=1}^{n} x_i$ 如果用 Python 写，对应什么代码？（提示：`sum(x[i] for i in range(n))`）
2. **argmax 的陷阱**：如果两个位置都是最大值，argmax 返回哪个？（提示：通常返回第一个，但这是个值得留意的边界情况）
3. **为什么不是 log₂ 或 log₁₀**：ML 几乎都用自然对数 ln（底数 e），为什么？（提示：求导时 $\frac{d}{dx}\ln x = \frac{1}{x}$，常数项为 1，最简洁）
4. **复合函数拆解**：y = sigmoid(Wx + b) 能拆成几层？每层是什么？（提示：内层仿射变换 Wx+b，外层 σ(·)）
5. **向量 vs 列表**：Python list `[1,2,3]` 和 NumPy array `np.array([1,2,3])`，乘以 2 结果分别是什么？（提示：试试看，一个会复制，一个会逐元素乘）
