## 二、结构性改进

### 2.1 新增 Ch0：数学预备知识

**理由**：README 声称"高中数学水平即可起步"，但 Ch3 很快进入贝叶斯、MLE，Ch4 直接讲 SVD 和矩阵求导。基础薄弱的学生会在 Ch1 就被 Σ 求和符号、下标上标、矩阵写法卡住。

**建议内容（严格控制在 4 个板块，不超过 150 行）**：

1. **符号速查卡**（最重要）
   - Σ 求和、Π 连乘的含义和手算例子
   - 下标/上标约定：x_i、W^{(l)}
   - argmax / argmin
   - log 和 exp 的 3 条核心规则（为什么 ML 爱用 log）
2. **函数复合**（链式法则前置）
   - f(g(x)) 的直觉：输入→中间结果→输出
   - 一个简单例子：y = (2x+1)²
3. **坐标系与向量图**
   - 点、向量、斜率在图上是什么
   - 只需一张图 + 3 段话
4. **NumPy 极简入门**
   - array 创建、shape 查看、矩阵乘法（@）
   - 10 行代码搞定，不展开

**不放入 Ch0 的内容**（这些属于初中数学，放进来会让 Ch0 变成一本初中教材）：
- 一元一次方程、二次函数
- Python 列表操作基础
- 坐标系画图详解

### 2.2 Ch9 拆分

**现状**：一章同时覆盖 Scaling Law + OLS + Policy Gradient + REINFORCE + PPO + GRPO + DPO，信息量约等于其他两章之和。

**建议拆成**：

- **Ch9 Scaling Laws**：幂律、Kaplan 缩放定律、Chinchilla、OLS 拟合、计算预算分配
- **Ch10 RL 基础与对齐**：Policy Gradient → REINFORCE → Actor-Critic → PPO → RLHF 架构 → DPO → GRPO

**为什么只拆成两个而不是三个**：
- PPO 既是 RL 方法论，又是 RLHF 的核心组件，强行拆开会打断逻辑链
- "RL 方法论→LLM 对齐应用"是自然的递进关系，放一章里更连贯
- 拆成两章后，Ch9 约 300 行（Scaling Laws），Ch10 约 500 行（RL+对齐），体量合理

### 3.3 "常见卡点"模块

**建议每章加一个 "⚠️ 常见卡点" 小节**（放在思考题之前）。每个卡点包含：困惑描述 + 类比/直觉 + 正确理解。举几个具体的例子：

**Ch2 卡点**：
```
卡点：偏导为什么只对一个变量求导？
直觉：站在山坡上，只朝东走，不看南北方向的高度变化。
      既然只朝一个方向走，其他方向当然不变——所以把其他变量当常数。
```

**Ch5 卡点**：
```
卡点：Adam 的 bias correction 到底在修什么？
直觉：m_t 是梯度的"移动平均"。刚开始 m_0 = 0，第一步 m_1 ≈ 0.1 × g_1，
      被初始化的 0 拉低了。除以 (1-β₁^t) 就是把被拉低的部分"补偿"回来。
      当 t 很大时 β₁^t ≈ 0，补偿消失。
```

**Ch6 卡点**：
```
卡点：KL 散度为什么不对称？
直觉：KL(P||Q) 问的是"用 Q 去编码 P 的数据，要浪费多少比特"。
      方向不同，浪费的量当然不同。就像用中文教科书学物理 vs
      用物理教科书学中文，难度完全不一样。
```

## 四、阶段项目（从"能看懂"到"能做出来"）

### 项目 1：从零实现线性回归（覆盖 Ch1-Ch3）

**为什么不是 Bigram 语言模型**：Bigram 本质是查表+概率统计，用不到 Ch1 的矩阵乘法和 Ch2 的梯度。线性回归能把三章内容全部用上：
- Ch1：矩阵表示（XW+b）、维度检查
- Ch2：梯度计算、梯度下降更新
- Ch3：线性回归的 MLE 解释（为什么 MSE 等价于高斯噪声假设下的 MLE）

**任务清单**：
```
1. 用 NumPy 构造数据（y = 3x + 2 + noise）
2. 手写前向传播：y_hat = X @ w + b
3. 手写损失函数：MSE = mean((y - y_hat)²)
4. 手写梯度：∂L/∂w, ∂L/∂b
5. 梯度下降循环：w -= lr * grad
6. 画出 loss 曲线和拟合结果
7. 验证：MSE 最小解 = 正规方程解 = MLE 解
```

### 项目 2：从零实现两层神经网络（覆盖 Ch4-Ch6）

**任务清单**：
```
1. 手写前向传播：h = ReLU(XW₁+b₁), y = hW₂+b₂
2. 手写交叉熵损失（Ch6）
3. 手写反向传播：用矩阵求导（Ch4）算 ∂L/∂W₁ 和 ∂L/∂W₂
4. 用 SGD 和 Adam 分别训练，对比收敛速度（Ch5）
5. 画出 loss 曲线、准确率曲线
```

### 项目 3：Mini Attention + 解码采样器（覆盖 Ch7-Ch8）

**任务清单**：
```
1. 实现 Q/K/V 线性变换
2. 实现 scaled dot-product attention
3. 实现 causal mask
4. 实现多头注意力拼接
5. 实现 temperature、top-k、top-p 三种采样策略
6. 对比不同采样参数的输出差异
```

**为什么项目 3 不覆盖 Ch9-10**：Scaling Law 和 RLHF 不适合"手写实现"——项目 3 覆盖到 Ch8 为止，Ch9-10 的验收用"论文阅读报告"或"复现实验"形式更合适。
